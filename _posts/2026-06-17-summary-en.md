This discussion highlights critical trade-offs between JWT and traditional cookie-based sessions, influencing authentication choices for web applications and potentially improving security practices. JWTs are stateless and cannot be easily revoked, making them vulnerable to long-lived token theft; cookies with HttpOnly and SameSite flags offer better protection against XSS but require CSRF defenses.

**Background**: JWTs are self-contained tokens that encode user claims and are signed by the server, allowing stateless authentication without server-side session storage. However, they cannot be revoked before expiry unless a denylist is maintained. Cookie-based sessions store a random session ID on the client and keep session data server-side, enabling easy revocation but requiring CSRF protection.

## [quicktok: A Faster BPE Tokenizer Matching tiktoken Exactly](https://www.reddit.com/r/MachineLearning/comments/1u73c5r/quicktok_a_faster_tokenizer_exact_and/) ⭐️ 8.0/10

quicktok is a new C++ BPE tokenizer that achieves 2-11x speedup over tiktoken while producing byte-identical token IDs. It supports popular encodings like cl100k, o200k, GPT-OSS, Llama-3, and Qwen2.5/3. Tokenization is a bottleneck in many LLM workflows, and quicktok's speed improvements can significantly reduce latency and cost for both training and inference. Its exact compatibility with tiktoken means it can be a drop-in replacement without any model changes. The speedup comes from a 2-byte trie for longest-match walks, dense exactly-keyed caches for merge-validity checks, and a hand-compiled pretokenizer instead of a general regex engine. Benchmarks on Apple M1 show quicktok (native) reaching 121.7 MB/s on The Pile, compared to tiktoken's 13.6 MB/s.

reddit · r/MachineLearning · /u/_casa_nova_ · Jun 16, 04:24

**Background**: BPE (Byte-Pair Encoding) is a subword tokenization algorithm used by most modern LLMs like GPT-4 and Llama. It converts text into tokens by iteratively merging the most frequent byte pairs. tiktoken is OpenAI's official BPE tokenizer, widely used but relatively slow. quicktok implements the same exact backtracking BPE algorithm as bpe-openai but with optimized data structures.

## [Bash /dev/tcp Enables HTTP Requests Without curl](https://mareksuppa.com/til/bash-dev-tcp-http-without-curl/) ⭐️ 6.0/10

A blog post demonstrates that Bash's built-in /dev/tcp feature can be used to make raw HTTP requests without external tools like curl or wget. This technique is particularly useful in minimal environments such as Docker containers where curl may not be installed. This trick provides a lightweight alternative for debugging and connectivity checks in constrained environments, reducing dependency on external tools. It highlights Bash's often-overlooked networking capabilities, which can be a lifesaver for developers working with minimal images. The /dev/tcp feature must be enabled at compile time with --enable-net-redirections, and it is not available on all systems (e.g., some minimal Docker images may disable it). The technique only opens a raw TCP socket, so users must manually craft valid HTTP requests and handle responses, which can be error-prone for production use.

hackernews · mrshu · Jun 16, 16:40 · [Discussion](https://news.ycombinator.com/item?id=48558018)

**Background**: Bash's /dev/tcp is a virtual file descriptor that allows opening TCP connections using redirection syntax. When compiled with networking support, Bash can read from and write to TCP sockets via /dev/tcp/host/port. This feature is often used for simple port checks or interactive debugging, but it is not a full HTTP client and lacks proper HTTP parsing.
